事情的开头只是想把自己在 Meta 这几年工作学到的东西传达给大家。到底数字广告是怎么运作的，为什么我不喜欢数字广告。于是开始用 coding agent 做视频。做是做出来的，但是效果没那么好。

之后看到了来龙去脉 LLQM 和一众 AI 生成视频之后，心里的 FOMO 又涌了上来。心里想着，我要做一个完美的 workflow，源源不断地产出视频。选题也可以让 AI 去抓。这期间是有几个不错的 idea，比如 Codex 玩魔兽，长途飞机上玩啥这种选题，稍稍有了一些流量。

日本之行算是一个小小的缓冲，让我从亢奋的状态里抽离了一下，专注在了旅行和剪辑 OSMO 4p 的录像上。

回国之后，看到了比特新语，意识到了 Opus 的优势，于是又转向了 Claude Code。尝试了 AutoTavern 这个选题，确实在 B 站有了很不错的流量。不过这个视频让我很别扭，原因在于东西是别人做的，原作者也发了类似的视频，我感觉自己就是个营销号，目的单单就是抓住用户的注意力，获得我也可以做到的那种成就感。

这个时候我开始思考，我到底想做啥视频。当时有个很模糊的想法，就是在这个生产力爆炸的时代，人本身反而变得更重要。我不想做一个科技号，一个科普号，一个教学号，而是一个真实的个人账号。不需要暴露太多个人信息，但内容需要是个人真诚传达的。有了模糊的想法，我开始弄下一个选题。当时上下班开车都放 QQ 音乐的刷歌，看到了无数的 tag（explicit，acoustic，等等），就想做个视频解释一下（其实还是没有完全跳出“我想解释点东西”的想法）。突然就想到了当时关于 hidden track 的故事，翻了翻自己的朋友圈，就打算把两个选题一起推进。

其中还咨询了一下老婆，调整了一下配音和节奏，做完先发了 hidden track 这个视频。这个视频我做得很用心，迭代了很多版，特别是配乐和如何 demonstrate gapless playback，还特意花了 20 多块做 b 站推广（哈哈哈哈 还是没忍住，因为真的很喜欢这个作品）。接下来的几天，收到了很多的点赞和评论，成为了至今为止最成功的稿件（虽然依然只是一个 100 粉丝都没有的小 up）。

每天我都会认真地看评论，看大家分享的故事，不同年龄、喜好的网友们从某一张 CD 第一次听到了 hidden track，第一次听到了连续的伴奏。我突然特别感动，我觉得我找到了自己想要做的频道的意义，并且因此发了个朋友圈。我这么写：“最近在用 Coding Agent 做视频，最新的一个稿件是关于听 CD 的故事。在评论和弹幕里看到网友类似的体验后真的很开心。科技滚滚向前，人与人之间真诚的分享永远有价值。”

再次回到频道的主旨，今天和老婆聊天的时候，慢慢地把它聊了出来。现在所有的视频 up 主都想教你用 ai，想告诉你某个事情的原理，想告诉你如何在这个时代 survive 下来。这样的内容太多太多了，这不是我想做的。这样的内容越多，越凸显了真实的故事、真实的连接、真实的人是多么重要，让大家能感受到 touching 和温暖。当然我不可能放弃 ai 制作，我依然会用 coding agent 做下去，依然会让 ai 帮我 research，不过在我的频道，只是一个真实的人在和你分享有趣的事情，仅此而已。
